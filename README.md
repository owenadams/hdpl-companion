# HDPL League Companion

A responsive league dashboard for fixtures, recent results, standings, player stats, team contacts and official links. Data comes from a JSON snapshot generated by the existing HDPL crawler.

## Run locally

```powershell
npm install
npm run dev
```

## Refresh the source data

The refresh script crawls the league pages, updates the Gemini context document and writes `public/data/hdpl-pages.json` for the app:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
& "c:\Users\owenc\Documents\Owen-AI\HDPL Skill Sync\scripts\update-hdpl-skill.ps1"
```

The Windows task refreshes the local Gemini context on Thursdays. The Pages workflow refreshes the public snapshot and deploys it daily at 12:00 London time, adjusting for GMT/BST.

## Production and offline use

```powershell
npm run build
npm run preview
```

The production service worker caches the app shell and latest league snapshot for offline use. PWA installation requires HTTPS when hosted publicly; localhost is supported for local testing.

The app links to the shared HDPL Gemini Gem by default. Set `VITE_GEM_URL` in `.env.local` only if you want to use a different Gem.

## GitHub Pages

The workflow in `.github/workflows/deploy.yml` builds the app with the repository subpath and deploys it whenever `main` is updated, when manually run, and after each daily data refresh. In the GitHub repository settings, set Pages deployment to **GitHub Actions**. The resulting URL will be `https://OWNER.github.io/REPOSITORY/`.
